# 任务二：合成旋转视频的参数拟合结果

## 1. 模型
采用正弦速度模型：
ω(t) = b + A * sin(Ωt + φ)
其中，A为振幅，b为平均角速度，Ω为频率，φ为相位。

## 2. 方法
1. 使用 C++ 结合 OpenCV 读取 `task2.mp4` 视频。
2. 通过 HSV 颜色空间提取青色发光小球，计算其质心坐标并求出每一帧的角度。
3. 将提取的数据导出为 `angle_data.txt`。
4. 使用 Python 的 `scipy.optimize.curve_fit` 进行非线性最小二乘拟合。

## 3. 拟合参数
- 振幅 (A): [-2.0074]
- 平均角速度 (b): [16.7948]
- 频率 (Ω): [1.3021]
- 相位 (φ): [-12.4781]

## 4. 误差指标
- RMSE (均方根误差): [9.2314] rad
- 有效样本数: 1440 帧
